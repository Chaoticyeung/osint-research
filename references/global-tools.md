# 通用 OSINT 工具

广泛使用且持续维护的是 **Bellingcat Online Investigation Toolkit**
(bellingcat.gitbook.io/toolkit),按类别索引工具并附用法和局限。配套的 **Verification
Handbook** 讲照片/视频溯源验证。GitHub 索引:jivoi/awesome-osint、edwardtay/awesome-OSINT。

下面按用途列常用条目,重点是溯源模式要用的。**任何单个平台都是能力示例,不是必须项;工具
状态会变,检索时复核当前可用性**。

⚠️ **反向图搜/人脸相似结果只是身份候选,不能单独确认个人**——必须再用其他公开锚点交叉确认。
**涉普通私人个人时,不用图像/人脸工具去扩展其无关的关系网**(受内核 5 最小化约束)。

## 反向图搜(追照片首发)

多引擎交叉,不同引擎覆盖不同:
- **Google Lens / Google 反向图搜**
- **Yandex** — 人脸和场景识别常比 Google 强,尤其非英语内容。
- **TinEye** — 强在按"最早被 TinEye 索引的时间"排序、以及找被裁剪/改版的图。注意:它给的是
  **最早已索引线索**,不等于网络首发时间(它没爬到的更早出处不会显示)。拿到候选后仍要回到
  该页面的实际发布时间、存档快照和原始发布者去验证,别把"TinEye 最早"直接当"首发"。
- **Bing Visual Search**

## 图片 / 视频元数据

- **EXIF 查看器**(如 exif.tools、Jimpl) — 读拍摄时间、设备、GPS(很多平台上传会剥离 EXIF,
  拿到原图才有意义)。
- **InVID / WeVerify** — 视频关键帧提取 + 反向搜 + 篡改检测,验视频首选浏览器插件。
- **FotoForensics** — ELA 误差分析,看图片是否被 P 过(需谨慎解读,不是铁证)。

## 网页存档

- **Wayback Machine** (web.archive.org) — 抓已删页面、看页面历史版本。
- **archive.today / archive.ph** — 覆盖不同,补 Wayback 的漏。**创建新的公开存档须遵守
  templates.md 证据台账里的授权和个人信息限制**(未授权/含敏感个人信息时改本地留存,不公开存档)。
- **图书馆/报刊数据库快照** — 部分旧内容只在订阅型库里留存,存档站没有时可退到这里。
  (注:Google 网页缓存和 `cache:` 运算符已停用,不再可用。)

## 视频溯源(先固定再分析)

- **下载/固定**:yt-dlp 等把原视频存下来(防删),再抽关键帧做反向图搜和逐帧分析。
- **InVID / WeVerify** — 关键帧提取 + 反向搜 + 篡改检测,视频核查主力(浏览器插件)。
- 从画面里逐帧找可定位特征:路牌、店招、车牌样式、语言文字、山形、天际线、基建。

## 地理定位(在哪拍的)

- **Google Earth(含历史影像)/ Google Maps 街景** — 比对建筑、地形、路牌;历史影像能匹配
  拍摄年份的地貌。⚠️ 街景不覆盖中国大陆,国内定位靠卫星图 + 本土地图(高德/百度)+ 实景。
- **卫星影像**:Sentinel Hub / Copernicus(免费、可查历史)、Microsoft Planetary Computer(Sentinel-2
  约 10 米分辨率、约 5 天一景,Explorer 网页免注册可浏览)、Google Earth,用于把地点收敛到坐标、
  核对拍摄时点的地面状态(施工/植被/积雪)。
- **Overpass Turbo (OpenStreetMap)** — 按地物特征(加油站、塔、桥)搜候选地点。

## 时间定位 chronolocation(什么时候拍的)

- **SunCalc** (suncalc.org) — 给定地点和日期,查太阳/阴影的方位和长度;反过来用画面里的
  阴影角度和长度,推拍摄时间与朝向。
- **Bellingcat Shadow Finder** — 由阴影反算可能的时间/纬度带。
- 交叉:天气记录、植被季相、施工进度、广播节目单、可见钟表/日历。

## 物理 / 环境旁证(近年事件核实)

原则:声称"某时某地发生了 X",就去找当时当地会被机器自动记录、且与当事人无关的公开数据。
这类记录不受叙事影响,是最硬的时空一致性检验。优先选**有历史存档**的源,只显示"现在"的
实时看板(如 ShadowBroker 这类聚合平台)对回头查已发生的事帮助不大。各源的访问门槛分三档:
**免注册**(网页直接查)/ **免费注册**(留邮箱拿 key,几分钟)/ **需申请**(说明用途、等审批)。
没登录态时先用免注册档,别在第一层就卡住。

- **NOTAM(航行通告)历史** — 事发当晚空域有无临时限制,可指向计划中的军事/航空活动。
- **METAR / 历史气象** (如 ogimet、wunderground history) — 当时天气,可解释"发光体"
  是否为寻常光学现象。
- **航班动态存档** — Flightradar24、FlightAware:免注册只能看近几天,历史回放要付费订阅。
  免费补充:adsb.lol(免注册,含军机 ADS-B,ODbL 开放数据,历史归档见其 GitHub 数据发布)、
  OpenSky Network(实时接口匿名可用但限流;历史数据库**需申请**,面向研究用途)。
  ⚠️ ADS-B 靠志愿接收站,中国大陆境内覆盖稀疏,查不到不等于没飞。
- **船舶 AIS** — MarineTraffic:免注册看实时,历史航迹付费。aisstream.io 免费注册拿 key,
  但只有实时流、没有历史,回头查用不上。涉渔船、走私、非法捕捞用 **Global Fishing Watch**
  (渔船活动事件,有历史,CC BY;网页地图免注册可看,API 免费注册拿 token)。
- **火情 / 爆炸** — NASA FIRMS 火点热异常存档(VIIRS/MODIS;网页地图免注册,批量下载
  历史用邮箱免费申请 MAP_KEY),核实"某地某晚起火/爆炸"是否
  有卫星热信号;⚠️ 小火、室内火、云层遮挡可能漏检,漏检不算反证。
- **地震 / 火山** — USGS 地震目录、Smithsonian 全球火山计划,均免注册,核实自然灾害类传闻的
  时间地点。
- **断网** — IODA(佐治亚理工互联网断网监测,基于 BGP 与主动探测,有历史,免注册),核实"某地断网/
  封网"说法及其起止时间。
- **地表变化** — Sentinel-1 SAR(Alaska Satellite Facility 检索免注册,下载要免费的 NASA Earthdata
  账号)、NASA OPERA(同用 Earthdata 账号)/ Copernicus EGMS(免费注册)地表形变与洪水淹没产品,
  穿云穿夜,可核实洪水范围、爆炸坑、大面积拆建。门槛最高、解读也最专业,只在其他旁证都没有时上。

## 跨境主体尽调(中国境内主体以 china-sources.md 为准,这里是境外/跨境补充)

尽调对象在境外或有跨境结构时,按下面的类别各查一遍,别只靠一个公司注册库:

- **公司注册与受益所有人**:OpenCorporates(跨国登记聚合);各国官方注册处(英国 Companies
  House、新加坡 ACRA、香港 ICRIS 等);受益所有人(UBO)登记(部分法域公开)。注册库证明的是
  "登记事实",不等于实际经营或控制关系。
- **证券监管披露**:上市/发债主体查当地监管(美国 SEC EDGAR、香港 HKEX 披露易等)——年报、
  重大事项、处罚。
- **制裁名单**:OFAC(美)、EU/UK 制裁名单、联合国清单。合作/交易前必查,但**名字命中只是
  "潜在匹配",不是硬红旗**——制裁搜索是模糊匹配,同名极多。必须进一步核实身份、清单类型、
  当前是否有效、以及是否适用于你所在法域,确认后才作为合规事项处理(OFAC FAQ 246)。
- **政治公众人物(PEP)**:OpenSanctions 等聚合库。**PEP 身份不等于违法或犯罪**,它只是
  "强化尽调(EDD)"的触发条件——命中意味着要多查一层资金来源和关联,不意味着定性(FATF R.12/22)。
- **通缉/执法名单**:各国执法机构公开通缉库。同样按"待核线索"处理,核实是否本人、案件状态。
- **法院与破产**:当地法院记录系统、破产/清算登记(如美国 PACER、英国 Insolvency Register)。
- **牌照与监管资质**:对方声称持牌时,回到发牌监管机构官网核验(金融、医疗、律所等),
  防伪造资质。
- **调查性泄露库**:ICIJ Offshore Leaks(离岸公司)——用于线索,注意合法性边界,不作定论。
- ⚠️ 查个人的用户名/邮箱聚合、泄露密码类工具(Sherlock、Have I Been Pwned 等)属于 OFM 原版
  的泄露层,合法商业尽调不用——见 SKILL.md 的边界说明。

## 用法提醒

- 多模态溯源工作流:固定原件(下载/存档)→ 反向搜追首发 → 地理定位(卫星/街景/OSM)→
  时间定位(阴影/太阳/语境)→ 核对时空一致性 → 物理旁证。单靠一张"看起来像"的图不能定性。
- 每一步把坐标、比对截图、工具和判断记进证据台账(见 report-structure.md 的证据台账/来源留痕)。
- 工具会失效、会改版。以 Bellingcat toolkit 的当前条目为准,本清单是常用锚点。
