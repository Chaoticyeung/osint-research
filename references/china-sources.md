# 中国信源清单

按记录类型组织。带 ⭐ 的是各类最常用、命中率最高的。**证明力不由"官方还是民间"决定,而取决于
来源对具体主张的直接获取能力**(见内核 2 来源—主张匹配)。多数需要浏览器访问,部分要账号或
付费;WebSearch 对国内站命中不稳,优先直接访问已知站点或走浏览器。

**工商穿透:聚合器通常更高效,但不是普遍规则。** 天眼查/企查查/启信宝把历史股东、变更、股权
穿透图整理好、且不像 gsxt 每查一次拦一次验证码,做多层穿透时通常更省事;但**小型核查或聚合器
不可用时,官方系统(gsxt)完全可以是主要入口**。关于聚合器:
- **别笼统称"持牌企业征信机构"、别猜其数据来自"授权采购+爬虫"**。企业征信是**备案**制度不是
  发牌;品牌名不一定等于实际备案的法律主体。是否完成备案,按其**实际运营法律主体**对人民银行
  最新备案名单核;**备案≠监管部门为其数据质量/完整性/合规性背书**。
- 平台标注的"疑似实际控制人""最终受益人"等**可能是算法推算,不等于官方受益所有人备案记录**。
- 关键、争议或对当事人不利的结论,仍要回官方一手**核单条**(见内核 4);"核单条"不是把整张
  穿透图在 gsxt 上重搭一遍。
- **gsxt 前台每次查询弹图片验证码、无法批量、名称需精确(注销/改名即漏)**,所以只用于
  spot-check 单条,不做批量穿透。

**可访问性是随时间/地区/账号/验证策略/产品版本变化的,不是永久事实:**
- 开始任务时先做一次**实际访问测试**。若遇地域或登录限制,记录**测试日期、网络区域、错误表现**,
  再选官方源/其他聚合入口/用户授权的登录态。(实测记录:2026-08 马来西亚 IP 访问天眼查被地域
  拒;这是当时当地的观察,不代表任何时候任何地区都封。)
- **登录/付费/验证码:不绕过。** 用户有合法访问权并自行完成登录/付费/验证后,可在其授权的
  登录态内协助检索;否则只记录访问限制和可行下一步。验证码一律用户完成(安全 + 反爬红线)。

isgmena/china-osint,以及历史考证需要的传统信源。

## 一、机构登记与文书(证明力取决于该来源对具体主张的获取能力)

### 企业 / 主体
- ⭐ **国家企业信用信息公示系统** (gsxt.gov.cn) — 工商登记、股东、变更、行政处罚,官方权威。
- ⭐ **天眼查 / 启信宝 / 企查查** — 聚合工商+涉诉+关联图谱,好用但深度数据要付费;
  免费层足够做初筛。注意它们之间会互相抄,不算独立信源。
- **裁判文书网** (wenshu.court.cn) — 涉诉记录。近年公开度下降。**查到只证明"存在相关裁判
  记录",不自动等于当事人有过错或当前仍有风险**——要看清案件角色(原告/被告/第三人)、
  结果、是否已履行/撤销/改判,再判断其意义。
- **中国执行信息公开网** (zxgk.court.gov.cn) — 被执行人、失信被执行人、限高。尽调必查;
  同样要看当前状态(是否已结案/履行完毕)。
- **信用中国** (creditchina.gov.cn) — 行政处罚、失信、红黑名单聚合。
- **巨潮资讯网 Cninfo** (cninfo.com.cn) — A股上市公司公告、财报、招股书,权威一手。
- **中国政府采购网 / 招投标** — 中标记录**只证明取得过项目**,不单独证明已履约、已确认收入
  或具备相应经营规模;要结合履约/验收/回款等其他证据才能谈规模。
- **香港公司注册处 (ICRIS) + 香港司法机构 (judiciary.hk)** — 涉港主体查这里。

### 机构 / 政府沿革
- ⭐ **各级政府公报、机构改革方案** — 机构是否存在、隶属谁、何时设立撤销。
- ⭐ **地方志 / 部门志 / 单位沿革志 / 年鉴** — 中国方志网、地方图书馆数字方志库。
  机构考证的金矿,机构历史常只在志书里有完整记载。
- **国家统计局** (stats.gov.cn) — 历史普查、经济指标。

## 二、学术层

- ⭐ **CNKI 中国知网** (cnki.net) — 论文**作者单位栏**是旁证机构存在与参与度的经典渠道;
  即使查不了全文,题录和作者单位常可见。全文多需机构订阅。
- **万方 / 维普** — CNKI 的补充,交叉覆盖。
- **学位论文** — 致谢和导师单位常带出编制信息。

## 三、严肃媒体存档层

- ⭐ **找首发,不找汇编。** 用报刊索引和旧报库定位最早报道。
- **人民日报图文数据库、各大报纸历史数据库** — 多需订阅,部分图书馆可访问。
- **全国报刊索引** (cnbksy.com) — 近代到当代报刊题录检索。
- 具体报道全文常要配合 Web Archive 找快照(见网络考古层)。

## 三·五、机构公开记录入口(轨迹领域,按"记录产生者"查)

**别只盯工商+新闻。** 按 `public-trace-index.md` 的轨迹领域矩阵,逐领域找中国的机构公开记录:

- **教育与能力**:学校/院系官网录取与新生名单、教育考试院公示、竞赛主办方获奖名单
  (如学科竞赛、创新大赛)、奖学金/荣誉/优秀毕业生公示、保送公示。
- **学术创作**:CNKI/万方/维普(论文题录+作者单位)、国家知识产权局(专利/商标)、
  国家自然科学基金/社科基金(课题)、作品著作权登记。
- **职业履历**:用人单位/高校"师资队伍""团队成员"页、行业协会会员/理事名录、会议议程与
  讲者简介、招录/任职/资格公示。
- **社会参与**:协会/基金会理事名单、捐赠公示、活动主办方的参会/嘉宾名单与活动照片。
- **历史档案**:校史馆/校友录、年鉴、地方志(中国方志网)、旧报刊库、讣告。
- 这些多为静态公示页,搜"姓名 + 机构/竞赛/年份"或直接进主办方官网+Wayback 存档。

## 三·六、本人及第三方公开表达来源

对应轨迹矩阵的"公开表达"领域——本人主动公开的内容 + 第三方(媒体/他人)的公开记录。**它是
众多来源之一,不是每次人物调查都要单独跑的"必经层";只在目标按常理可能公开表达/互动/露面时
才重点查。**

- **微博/微信公众号视频号/抖音/快手/小红书/B站**:个人号、公司/品牌官号、@提及、活动合影、
  探店露面。先查公司/品牌官号,再看运营人/法人有没有公开露脸。
- **脉脉/领英**:职场自述、任职、同事关系。
- **贴吧/豆瓣/知乎**:观点、兴趣、被讨论。
- **考古(Web Archive 可抓已删)**:QQ空间/人人网/开心网早年公开日志、相册。
- **游戏平台动态**(战绩/动态分享):**低优先级**,仅当与关键问题强相关且能锚定身份时才查。

**技巧:从"发射者"反挖"零发射者"。** 刻意无痕的人自己不发,但同框的**发射型目标**(爱晒的
公众人物、合作方)会。挖那个发射者的公开足迹(活动合影、@提及、被 tag 的照片),常能捞到
无痕者的脸或名字——这是溯源反向图搜**可能的"种子图"来源之一**(机构官网、会议照片、学校公示、
新闻报道也都可能提供种子图)。

⚠️ **合规硬约束(受内核 5 与 reading-signals.md 三重门槛管辖)**:
- 对**公众人物/自我公开者/公开面向公众的账号**(公司官号、公开自媒体)最正当;对**私人个人**
  必须过**真实性/相关性/比例性**三重门槛,只取与调查角色直接相关的,**不拼凑私生活画像**。
- **身份锚点**:名字撞一个号不等于本人;没有可靠公开标识(账号自陈的公司/职务、与已知事实
  交叉吻合)锚定前,只当"疑似,待核",不并入结论。不靠私密标识(手机号/身份证)反查绑定。
- 目的限定:为回答关键问题服务,不为猎奇扩展收集。

## 四、当事人一手层

- **讣告** — 生平介绍常写出服役/任职单位全称和年份,机构考证极有用。
- **回忆录、口述史、人物传记** — 图书馆、孔夫子旧书网(找绝版)。
- **采访视频 / 播客** — 同一人多次采访按时间排序对比,看说法是否随时间膨胀。

## 五、网络考古层(最软,交叉用)

- ⭐ **Wayback Machine** (web.archive.org) — 抓已删网页、页面历史快照、找报道原文。
- **archive.today / archive.ph** — 另一套存档,覆盖不同、可补 Wayback 的漏。
- ⭐ **自由微信 (freewechat.com) / 自由微博 (freeweibo.com)** — GreatFire 的公开镜像,专门备份
  **被删的微信公众号文章和微博**。国内平台删帖激进,原文常在这里还能找回——"删帖 ≠ 消失",
  删除动作本身是信号(见 reading-signals.md),而被删内容往往是最有价值的一手。
- **老论坛存档** — 天涯、西陆、贴吧等的历史帖(多已删,靠存档)。
- ⚠️ 这一层循环引用最严重,所有信息都要回溯最早源头、比对是否同源(见 methodology.md)。

## 尽调专用快查顺序

摸一家公司 + 实控人(开工先测当前可用性:聚合器不可用时改用官方 gsxt、其他聚合入口或用户
授权登录态):
1. **聚合器(天眼查/企查查/启信宝)通常最快**——历史股东、变更时间线、对外投资、疑似实控人、
   股权穿透图、涉诉/被执行/处罚汇总,一站拿全。深度数据登录(ego-browser,用户登录我检索)。
2. **gsxt**——聚合器不可用或小型核查时可作主要入口;有具体记录要官方核对时也去这里(前台每查
   一次弹验证码,适合核单条不适合批量穿透)。
3. 执行信息公开网查被执行/失信、信用中国查行政处罚——作官方核验补充。
4. **裁判文书网(登录态)反搜代持/借贷/股权/执行异议纠纷的判决书事实**——这是可能暴露隐名
   出资人的独有渠道,聚合器的"涉诉"标签替代不了读判决书原文。
5. 新闻搜索 + Wayback/自由微信 查负面舆情和关联公司暴雷。
穿透代持/找真实控制人的完整打法见 `follow-the-money.md`。
