这两套是情报分析界的公开标准做法,用来对抗"证到自己想信的结论"这个最常见的失败。

## ACH(Analysis of Competing Hypotheses,竞争性假设分析)

CIA 分析师 Richards Heuer 提出。核心一句话:**不要找证据支持你的假设,要用证据去排除假设。**

普通人调查一件事,会先有一个倾向的答案,然后不自觉地只收集支持它的证据(确认偏差)。ACH 反过来:

1. **列假设。** 把主要说得通的解释都列出来,包括你不喜欢的。假设应**尽量互斥、覆盖主要解释**,
   但不必强求形式上绝对穷尽(可留一个"其他/未知"兜底)。
   例(考证"某机构是否存在"):
   - H1:真实存在,且职能如传闻所述
   - H2:真实存在,但职能普通,被传言加工放大
   - H3:纯属虚构,所有信源可回溯到单一源头(如某个人的自述)
2. **列证据。** 把每条查到的事实(和查不到的关键事实)列成行。
3. **做矩阵。** 行是证据,列是假设。每个格子填这条证据对这个假设是"一致 / 不一致 / 无关"。
   重点标注**不一致**——一条能否定某假设的证据,价值远高于一条"符合"某假设的证据,因为
   "符合"往往对多个假设同时成立,没有区分力。
4. **看哪个假设的"不一致"最少。** 存活假设不是被证据支持最多的,而是被证据推翻最少的。
5. **关键假设检查。** 每个假设都压在一些"默认为真"的前提上(如"这类机构照例会进沿革志")。
   把这些前提显式列出来,逐个问"它要是错了呢"——前提一塌,建在上面的判定跟着塌。
6. **敏感性分析。** 找出在"扛"结论的那一两条证据:如果它被推翻/降级,存活假设会不会换?
   会换,说明结论脆弱,要么补独立印证,要么调低置信度。别让结论压在单条未复核的证据上。
7. **诚实标注 + 未来观察指标。** 证据不足以区分时,如实说"当前证据无法区分 H2 和 H3",不硬选;
   并列出"后续出现什么信息应重新评估"(某档案解密、当事人新发声、新的一手文书),
   让结论保持可被将来推翻的开放状态。

## 缺席证据:什么时候"查不到"才算数

"查不到痕迹"可以是有力证据,但**只在"预期可观察性"成立时**:即"如果 H 为真,某处本应留下
可查的痕迹"这个前提站得住。前提不成立时(比如涉密单位本就不进公开机构序列),零命中什么
都不说明。下"缺席即反证"的结论前,过这张清单,并把它记进证据台账:

- **预期可观察性**:若为真,它该在哪类库留痕(沿革志/论文单位栏/讣告/公报/注册登记)?
  说得出具体位置,缺席才有意义;说不出,就不是缺席证据,只是"没找到"。
- **判"未发现某类公开足迹"前,先覆盖相关的记录产生者**:识别与该假设相关、且**按常理会产生
  记录**的主要机构和第三方记录产生者(见 `public-trace-index.md` 轨迹矩阵:学校/协会/法院/
  登记机关/媒体/本人账号…),覆盖其中预期可观察性较高的记录族。社交平台只在目标**按常理可能
  公开表达、互动或露面**时才是必查来源之一,不是每案的强制层。只查了新闻+工商就说"此人零足迹",
  是把检索范围的洞冒充成事实——**尤其当"无足迹"被当成"名义人/白手套"信号使用时,该信号只有在
  覆盖了预期会留痕的记录族之后才成立**。
- **别名与旧称**:换了名字/编号/简称/英文名再查了吗?漏一个别名就可能假阴性。
- **时间与数字化覆盖**:年代太早的材料可能从未数字化;确认目标年代在所查库的覆盖范围内。
- **库的访问限制**:付费墙、登录墙、地域封锁会让你"看不到"≠"不存在";记下哪些库没查全。
- **检索记录**:实际查了哪几个库、用了哪些关键词/别名、覆盖时间段——写进台账,否则
  "查过了"不可复现,别人无法检验你的"零命中"。

满足这些,零命中才作为对该假设的"不一致"计入矩阵,并如实标注检索边界。

## Admiralty 信源评级(NATO 军标)

给每条关键信源打两个**相互独立**的维度,写成如 "B2" 的组合。**两维必须分开判,不要联动**:

- "来源可靠性"看的是**谁在说**(这个来源历史上准不准),与这条信息本身是否属实无关。
- "信息可信度"看的是**这条内容本身**(有没有被独立印证、与已知是否矛盾),与来源身份无关。
- 常见错误:把"官方发布"自动打成 A,把"有旁证"自动打成 1。**都不成立**——官方也会发布未经
  核实或事后证伪的信息(可靠来源+存疑内容 = 如 A4 完全正常);一条被多方独立证实的信息,
  即便来源普通,信息维也可以是 1。NATO 原始说明本身就强调:来源通常可靠 ≠ 每条信息必然正确。
- **动机 → 定"查什么",不直接改真假**:一方有利害(当事人否认丑闻、工作室护盘,或爆料方
  图流量/报复)提示"这里要多查一层、找可验证细节",**不等于该声明/爆料就假**。对否认方和
  爆料方对称怀疑,别只降一边的分。怎么读行为信号并列替代解释,见 `reading-signals.md`。

**来源可靠性(A–F):**(看来源的历史准确率,不看它是不是"官方")
- A 完全可靠(在相关领域长期表现完全可靠;实际使用中极少评为 A)
- B 通常可靠(权威媒体、可信机构)
- C 比较可靠(一般有信誉的来源)
- D 不太可靠(时对时错)
- E 不可靠(历史多次出错)
- F 无法判断可靠性

**信息可信度(1–6):**
- 1 已被其他独立信源证实
- 2 很可能为真(符合其他已知信息)
- 3 可能为真(部分印证)
- 4 存疑(无印证但不矛盾)
- 5 不太可能(与已知信息矛盾)
- 6 无法判断真伪

用法示例(两维分开判,评级随印证情况变化,不是查表):
- 机构沿革志里的隶属关系,且有另一独立来源印证 → 来源等级按其在相关领域的历史表现和信息
  获取能力评定(沿革志对"隶属沿革"有直接获取能力,可较高),信息维 1(已印证)。
  但**若无旁证且与其他材料矛盾**,同一来源信息维可能是 5(可靠来源+矛盾内容)。
- 权威媒体首发报道,尚无第二家独立证实 → B3 左右;被独立复核后信息维升到 B2/B1。
- 当事人自述、无第三方旁证 → 来源可靠性看这个人(C/D),信息维 4(存疑,无印证);
  注意:当事人对"自己经历过什么"可靠性较高,对"这机构到底干什么"往往降级。
- 匿名网帖 → 来源 F,信息维看能否印证(多为 4 或更低)。

**评级本身不下结论,它让你的结论透明:** 读者一眼看出某个判断是压在 A1 上还是压在 F4 上。

## 信源评级 ≠ 结论置信度

两个不同层级的东西,不能互相替代:

- **信源评级(Admiralty)** 评的是**单条证据**——这一条来源多可靠、内容多可信。
- **结论置信度(高/中/低)** 评的是**整体判断**——把所有证据放一起权衡后,对某个结论有多大把握。

一条 A1 证据不等于结论就"高置信"(它可能只覆盖问题的一小块);反过来,多条各自平庸(B3/C3)
但相互独立、彼此印证的证据,可以支撑一个"高置信"结论。判定标准:

- **高置信**:证据直接覆盖核心主张、关键替代解释已被排除。简单登记事实可由**一份真实、直接、
  完整的一手文书**充分证明;**争议性、不利或复杂主张**还应完成与风险相称的独立印证。
- **中置信**:有正面证据但印证不足,或存在未消除的替代解释,或依赖某条尚未复核的关键证据。
- **低置信**:证据稀少/单一来源/循环引用未排除,或存活假设不止一个而证据无法区分。

结论里写置信度时,一句话说清它为什么是这一档(靠什么撑起来、还差什么)。

## 认知偏差检查清单(下结论前自检)

- **确认偏差**:我是不是只找了支持既有倾向的证据?反面证据认真找了吗?
- **锚定**:第一个看到的说法是不是过度影响了我?
- **叙事诱惑**:我是不是因为"这样讲更精彩/更完整"而倾向某个结论?现实往往平淡。
- **权威光环**:某个信源可信,是因为它真的可靠,还是因为它有名/有官方身份?
- **将缺席当存在**:我有没有把"没查到反证"误当成"证明为真"?
- **把转述当原文**:我引的这句话、这个数字,是从一手页面逐字抄的,还是某个摘要替我概括的?
- **囿于见闻**:我的来源是不是都站在同一个位置上看这件事?换个位置的人会看到什么我看不到的?

## 循环引用的识别(这类调研最大的坑)

十个网站说同一件事,不等于十个独立信源——很可能是一个源头被转发了十次。识别方法:

- **比对措辞**:多个来源用词高度雷同 → 同源转载。
- **比对错误**:如果它们连同一个具体错误(错的日期、错的人名、错的数字)都一致 → 铁证同源。
- **回溯最早**:按发布时间往回追,找到最早那一篇。常见结果是所有链路收敛到单一源头
  (某人的一次采访、某个帖子)。这时"信源众多"的假象破灭,实际证明力等于那一个源头。

真正的独立印证,是两条**信息获取路径不同**的来源:官方文书 + 当事人回忆,或
媒体现场报道 + 物理记录(气象/航行数据)。

## 覆盖缺口:真实性之外的另一种不足

交叉印证、Admiralty 评级、循环引用检查,处理的全是同一个问题:**这条信息是不是真的**。
但调查还会在另一个维度上失败:每条都真,合起来仍然看不见全貌,因为所有来源站在同一个位置上。
毛泽东在《反对本本主义》里把这种失败叫"囿于见闻",并给了一条粗暴但管用的下限:调查会
"至少需要三人,不然会囿于见闻,不符合真实情况"。

两种缺口的症状和补法都不同,诊断错了就会白费力气:

| | 真实性缺口 | 覆盖缺口 |
|---|---|---|
| 症状 | 单一来源、循环引用、来源不可靠、细节无法核验 | 来源都可靠,但视角单一;换个角度的问题答不上来 |
| 补法 | 找**更可靠**的源、找独立获取路径、回溯到一手件 | 找**位置不同**的源 |
| 记在哪 | 台账评级列、"查不到/存疑" | 纲目的覆盖标注、交付的覆盖声明 |

**怎么判断来源的"位置"**:同一件事,谁在什么身份上、通过什么渠道知道它。公司自述、客户、
供应商、离职员工、监管机构、竞争对手、法院、媒体,是七个不同位置。三份公司自己的材料
(官网、招股书、公关稿)是**一个**位置,不是三个。取证时在台账里记下每个来源的位置,收口前
数一数覆盖了几个位置——**位置数比来源数更能说明调查做得深不深**。

选位置不是越多越好,按"哪个位置最可能持有与现有结论相反的信息"排序,优先取那个。

## 一手原文纪律:什么能当证据摘录

**能当摘录的**:一手页面/文书本身的逐字原文(自己打开读到的)、官方公告与登记记录原文、
判决书裁判文书原文、当事人自己发布的内容原文。

**不能当摘录的**:搜索结果摘要;WebFetch 之类工具用小模型生成的页面概述;百科、汇编、
媒体对他人材料的复述;自己凭印象的转写。这些能用来**找线索**,不能用来**当证据**。

理由不是形式主义。这类概述会系统性地抹掉三样东西,而这三样恰好是调查最吃紧的地方:

- **限定词**:"部分""疑似""据称""拟"在概括中最先消失,主张因此被悄悄强化。
- **精确值**:人名的字、机构的全称、日期、金额、百分比,概括时常被四舍五入或省略。
- **归属**:原文里"某人称"的东西,概述里会变成无主语的陈述,像是页面自己的认定。

**操作规则**:

1. 关键事实先拿到一手页面。抓取失败(编码乱码、扫描件 PDF、403、JS 渲染)就换浏览器直接读
   页面文本,或找同一文件的其他托管处,别拿概述凑数。
2. 台账"原文摘录"列只放逐字原文,带引号。转述一律不进这一列。
3. 确实只拿得到转述的:该事实**可信度降一级**,摘录列写"仅得转述(来源:<工具/二手源>)",
   并放进"内部待核",不进已证事实层。
4. 二次加工材料(百科、综述、媒体复述)标了出处的,顺着出处回到一手件再引用;没标出处的,
   只当搜索线索。
5. 记录不假手于人:重要材料自己读过、自己摘过,才算查过。让别的工具或代理代读的,按第 3 条办。

## 个人信息合规底线(尽调/涉活人时的四道自检细则)

SKILL.md 的强制原则在这里展开成可判定的标准。涉及在世个人时逐条过:

1. **用途正当**:先写清这次核查服务于哪个具体决策(合作准入/授信/招聘背景)。收集范围以该
   用途为界。
2. **识别实际适用法域**:对象、数据、你自己可能落在不同法律下(中国《个人信息保护法》/GDPR/…)。
   识别实际适用的法域;**不确定时采用保守内部控制,但不冒充法律结论**(不替代法律意见)。
3. **身份消歧——不靠身份证号**:同名同姓极常见,错把 A 的记录安到 B 头上会造成实害。确认
   同一人靠**两个以上非敏感公开属性、或一个具有唯一性的公开身份锚点**交叉吻合;匹配强度取决于
   属性稀有度、时间一致性和来源质量,**不机械数数**。**不主动收集或使用身份证号码/号段**(敏感
   信息、与最小化冲突)。锚不定就标"疑似,待核",不并入结论。
4. **数据最小化 + 相关必要**:只收回答关键问题所需的最少信息。**不为猎奇或建立完整家庭画像而
   泛化收集**住址、行踪、联系方式、亲属关系、健康/宗教/生物特征。**但**:亲缘/私人关系若直接
   关系到代持、实际控制、利益冲突、共同受益或身份消歧,可作为限定范围内的调查假设——只收所需
   的关系和证据,不扩展到无关家庭成员及私生活。

**已公开信息不等于可随意处理。** 《个人信息保护法》第二十七条:个人信息处理者在合理范围内
可以处理个人自行公开或已合法公开的个人信息,但**处理对个人权益有重大影响的,应当依照本法
取得个人同意**(不是"可能需要",是"应当")。原文:npc.gov.cn。因此涉及重大影响时,要么
不做,要么走对方知情同意的正式渠道。

**重大权益决策不由公开信息自动下结论**:本 skill 的产出是风险线索,供人判断;不替你判定
"录用/拒绝/放款/准入",要给对象申辩机会和人工复核余地。

## 身份与关系:三个不同层级的结论,别混

关于"人"的判断要分清是哪一级,证据要求逐级升高:

1. **"是不是同一个人"(身份消歧)**:靠公开身份锚点(唯一任职/资质+时间地域)交叉吻合;
   锚不定就标"疑似,待核",不并入结论。
2. **"两人之间是否存在关系"**:有共同公司/交易/诉讼/共同活动等直接连接才成立。
3. **"具体是什么关系"(亲属/上下级/代持…)**:需家谱、讣告、人物介绍、判决、共同声明等
   明确指出,才能确认具体性质。

这三级不能跳:确认了"存在关系"不等于知道"是什么关系";名字/字辈线索(见 follow-the-money.md)
最多支撑到"较可能同一家族同一代际",到不了"是亲兄弟"这种具体断定。
