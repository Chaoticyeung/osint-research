# 穿透空壳:追资金与控制关系(follow the money)

**这不是第四种模式,而是考证和尽调都可调用的穿透子流程。** 当核心问题变成"某主体背后是否存在
**未披露的出资或实际控制关系**"时,切到这套打法。

**问法要中立,别预设幕后控制人存在。** 不是"揪出幕后金主"(那已经锚定了有幕后控制人),而是:
**是否存在未披露的出资/控制关系?现有证据分别支持哪些候选解释?** 默认候选解释谱系(中性):
名义人自有资金 / 共同投资 / 借贷 / 委托持股 / 代持 / 政策性资金 / 登记与实际控制不一致。
**"非法资金来源或掩饰资金性质(洗钱)"不是默认假设**——只有出现虚假交易、资金闭环、异常股权
层级、关联方循环转账等**前置指标**时才增加该假设,别让调查从中性验证滑向刑事猜测。

## 先认清天花板(管理预期,别对"查不出"感到意外)

在中国,一次专业的代持对 OSINT 大概率打不穿,不是你没努力:

- **受益所有人(UBO)信息不向社会公开**。中国已自 2024 年建立受益所有人备案制度,但备案信息
  只向国家机关和履行反洗钱义务的特定机构依法开放,**不对公众自由查询**——所以公开层拿不到
  实际受益人(这跟英国 Companies House 的公开 UBO 登记不同)。
- **完整银行流水通常不向公众开放**,但**部分资金事实可能通过替代证据浮现**:账户持有人自行提供、
  审计材料、上市公司披露、判决书"本院查明"的事实、破产程序、或其他依法取得的材料。公开调查
  不能自行调取完整流水,但可以去找这些公开或经授权形成的**替代证据**。早年灰色收益若没在土地、
  公司或诉讼里留渣,工商上就是空白。

这套打法的目标是**榨干公开层允许的一切**,同时诚实说明公开层根本不存在的东西(UBO、流水)
到此为止。

## 关于"名义人查无实业却能动大钱"这个信号——别把缺失当铁证

要把它当异常信号,得先满足两个前提,否则它只是**待解释的不一致**,不是结论:

1. **先证明"确实动了大钱"**:有可核验的出资额/交易记录(判决书、公告、股权对价、招股书等),
   而不是传闻里的"砸了十几亿"。
2. **确认相关经营、持股或资产按常理本应公开可见**:即"如果他真有对应实业/财富,某处本应留痕"
   (预期可观察性,见 methodology.md 缺席证据)。

两条都成立,"查无来源"才是异常;可以写成发现,但标清它是**不一致**、不是"证明了代持"。

## 打法(按"最可能撬开"排序;停止/升级用信息增益判断,不设固定次数)

### 1. 把裁判文书当资金线索挖(最容易被忽略、也最可能出成果)

代持一旦闹上法庭,隐名股东的名字就写在判决书里。不要只查"这个人有没有被告",要**反过来搜
能暴露资金关系的案由**:

- 关键案由:**股权代持纠纷、股权转让纠纷、民间借贷纠纷、合伙协议纠纷、委托理财、执行异议**
  (案外人主张"我才是真实权利人"的执行异议之诉,是代持现形的经典场景)。
- 搜索姿势:用名义人、与之直接相关的自然人、涉事公司名分别在裁判文书网/威科先行等检索,
  重点读**判决书"本院查明"部分的事实**——出资额、代持约定、资金往来常写在那里。
- 一份点名隐名出资人的生效判决,是这类案子里少有的**可独立核验的直接证据**(能把推断升到高置信)。

### 2. 关联自然人反查(限于与关键问题直接相关的人)

名义人自己可能是"白纸",但结构里**由登记文件、交易、诉讼或控制关系直接连接**的人未必。**只反查
这些直接相关的人**;亲缘关系若直接关系到代持、实际控制、利益冲突、共同受益或身份消歧,可作为
**限定范围内的调查假设**,但只收回答关键问题所需的关系和证据,不为建立完整家庭画像而泛化收集。

- 对象:其他股东、历任法定代表人、监事、**接盘人**(股份转给谁了)、香港公司的其他登记董事。
- 每人查:名下其他公司、对外投资、任职、司法记录——都在登记/公开商业信息层面。
- 逻辑:实际出资人有时把结构分散在可信第三人名下;顺着有直接连接的接盘人/共同持股人往回倒,
  常比盯着台前名义人有效。

**姓名结构与亲缘推断——四级规则(结论粒度必须匹配证据级别)**:

1. **同姓**:弱线索,只用于扩展检索。
2. **同姓 + 名字同一位置共享字符/部件**:提高"可能存在同宗同辈关系"的先验概率。共享字符既
   可能在名字第一字、也可能在第二字(如"甲承安 / 甲承远","甲"为虚构姓氏,共享"承"字)。
3. **再叠加**年龄接近 / 共同地域 / 共同公司 / 连续股权转移 / 长期共同任职 / 共同活动记录:
   可形成**中等置信的"疑似同宗同辈"**推断。
4. **家谱、讣告、人物介绍、判决、共同公开声明**等明确指出关系:**才确认具体亲属关系**。

结论粒度:可以推断"较可能属于同一家族的同一代际";**不能仅凭姓名断定"是亲兄弟",也不能在
兄弟/堂兄弟/族兄弟之间强行三选一**。字辈习惯在当代并不普遍、适用范围难仅凭名字确定,保持
保守。仍受最小化约束:不据此聚合无关家庭成员和私生活。

### 3. 股权穿透图实操(follow-the-money 的主干工具)

天眼查/企查查/启信宝当穿透工具用,但它们是**二手**(上游是 gsxt 官方),结论回一手核:

- **历史股东 + 变更时间线**:谁在什么时间进出,和其他事件对时间。
- **对外投资 + 疑似实际控制人 + 股权穿透图**:一层层穿,找共同控制人和资金闭环。注意平台的
  "疑似实际控制人""最终受益人"是**算法推算结果,不等于官方受益所有人备案记录**,当线索不当定论。
- **增资/实缴异常**:注册资本突然放大、实缴与认缴的差,钱从哪来是问号。

### 4. 验经营实质(判断是不是通道)——多项组合,不靠单指标

**零社保参保不能单独证明是空壳**——控股公司、特殊目的实体、项目公司都可能合法零雇员。它只是
"经营实质不足"的一项信号,要和多项组合起来看:

- 办公场所、实际人员、社保参保、真实合同/业务流、招投标中标、行政许可、纳税信用、审计意见、
  资金用途。
- 组合判断:宣称大体量,却办公虚设 + 零参保 + 无业务合同 + 无许可 + 无纳税痕迹——多项同时缺失,
  才指向"通道";单看一项(尤其零社保)不下结论。

### 5. 香港公司查册(ICRIS/CR)

涉港结构可走,能拿到内地拿不到的登记件,但注意公开查册的限度:

- **周年申报表(NAR1)/董事登记**:公众查册通常只显示**部分**身份/证件号码,完整号码和通常
  住址属受保护信息、不公开。部分号码 + 姓名拼写可用于**辅助同名消歧**,**不能证明亲属关系**,
  也不足以单独坐实身份。
- **董事其他任职反查**:用董事姓名反查其名下其他香港公司,作为搜索线索。
- 走法:香港公司注册处电子查册(ICRIS)付费流程;通常需用户侧操作,报告里点明这是可行的下一手。
  **产品种类、可见字段和收费会变,检索前查香港公司注册处最新查册说明及收费表**。

### 6. 不动产 / 法拍 / 抵押(反推真实资产)

不动产登记在中国不公开,但外围留痕:司法拍卖(阿里/京东司法拍卖历史)、抵押/查封(经裁判文书、
执行信息、工商动产抵押反推)。目的:验证名义人/关联人是否真持有能支撑其出资的资产。

### 7. 离岸与跨境(资金出境时)

OpenCorporates(跨国登记)、OpenSanctions(制裁+PEP)、ICIJ Offshore Leaks(离岸,线索用、
注意合法性边界)。见 `global-tools.md` 跨境尽调一节。

## 纪律(和 reading-signals.md、内核 5/6 一致)

- **"名义人查无实业却能动大钱"是不一致,不是结论;"所以是代持"是推断层**(中等置信上限),
  除非有**判决书、代持协议、审计材料、当事人承认、上市披露等直接证据**才升高。别把不一致直接
  写成代持。
- **对称怀疑**:名义人可疑不等于坐实其后有某个具体的人;给任何第三人安名字,必须有可独立核验
  的证据,否则只进"内部待核线索",不进结论、不对外发布。涉重大人物的高风险主张常存在匿名源、
  循环引用和来源不透明问题,**必须逐条回溯和评级,不因指向对象(哪怕是权贵/最高层)预设真假**。
- **合规**:受内核 5 约束——不聚合与关键问题无关的敏感个人信息、不建立与关键问题无关的完整
  家庭关系图(与代持/控制/共同受益/利益冲突直接相关的亲缘关系可限定范围调查)、涉重大权益
  决策只用已证事实。
- **诚实收口**:走到公开层天花板就明说卡在哪(需侦查权/付费查册/非公开数据),给可核实的下一手,
  而不是硬拼一个金主名字。
