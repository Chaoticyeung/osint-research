# 公开轨迹索引:从问题推导记录来源

这是本 skill 收集环节的主干。**不要从"平台清单"出发**(先想微博/工商/裁判文书再去撞),而要
**从关键问题出发,推导出"谁按常理会产生什么记录、记录在哪查、能证明什么"**。这对应情报收集的
标准结构:可观察指标 → 具体信息要求(SIR)→ 收集能力(谁/什么记录)。平台只是"检索入口"这一格,
不是起点。

## 收集链(人物/主体调查的推导骨架;按关键问题裁剪,不是每格都要填满)

```
关键情报问题(KIQ)
  → 候选假设(尽量互斥、覆盖主要解释,不强求绝对穷尽)
  → 可观察指标(若某假设为真,现实中会留下什么可观察的痕迹)
  → 具体信息要求(要拿到哪条具体信息才能确认/排除)
  → 记录产生者(谁按职责/习惯会产生这条记录:机构/本人/第三方)
  → 可能形成的记录(它长什么样:名单/公示/判决/年报/合影/域名…)
  → 检索入口(去哪查:官网/数据库/存档/聚合器/平台——见各信源文件)
  → 身份锚点(怎么确认这条记录属于目标本人而非同名)
  → 证据作用(它能证明什么、不能证明什么)
  → 可观察性边界(哪些该有记录却查不到=有意义的缺席;哪些本就不留公开记录)
```

**"记录产生者"是关键一环**:先问"谁有动机/职责把这件事记下来并公开",记录来源自然浮现。
学校产生录取/获奖名单,法院产生判决,协会产生理事名录,专利局产生专利,本人产生社媒发言——
它们都是"公开可得信息",没有"公开信息 vs 公共信息"的人为二分,只有"由谁产生、如何产生"的分类。

## 公开可得信息:按记录产生方式分类

不按平台分,按"记录怎么来的"分——这决定它的证明力和去哪找:

1. **机构产生的公开记录**:登记机关、法院、监管、学校、协会、政府发布的名单/公示/判决/年报。
2. **本人主动公开的内容**:社媒发言、采访、文章、视频、个人主页、代码提交。
3. **第三方公开记录**:媒体报道、他人合影/@提及、被访谈中被提到。
4. **商业数据库聚合信息**:天眼查/企查查/聚合搜索——二手索引,结论回一手核;算法字段(疑似
   实控人/最终受益人)是推算不是官方备案。
5. **历史档案与网页存档**:年鉴/校史/方志/旧报/Wayback/自由微信——考古层,找已删和早期痕迹。
6. **图像、视频、地理与技术痕迹**:照片视频(反向搜/EXIF/地理时间定位)、域名/App/代码时间线。

## 轨迹领域矩阵(记录产生者 → 典型记录 → 能证明什么)

调查一个人时,**按关键问题选相关的轨迹领域,不要求逐项全扫**;与假设无关的领域不收集。这张表
是**防遗漏**用的(别漏掉可能产生关键记录的机构),不是人物画像穷举表——别为了填满九格而扩展成
完整私人画像。选中的领域再问"这里有没有相关记录",而不是只盯工商+新闻:

| 轨迹领域 | 记录产生者 | 典型记录 | 能证明什么(严格) |
|---|---|---|---|
| 教育与能力 | 学校、教育部门、招生机构、竞赛主办方 | 录取名单、获奖名单、奖学金/荣誉公示、论文 | 某次录取/获奖/学术活动(单条≠"学习好") |
| 职业履历 | 用人单位、行业协会、会议主办方 | 任职公示、员工介绍、会议议程、讲者简介 | 某时间段的任职或专业活动 |
| 商业活动 | 登记机关、采购方、监管机构 | 工商变更、招投标、许可、商标、专利 | 登记关系、交易机会、经营活动 |
| 司法监管 | 法院、执行机关、监管部门 | 判决、执行、处罚、破产、法拍 | 诉讼角色、裁判结果、监管事实 |
| 学术创作 | 高校、期刊、专利机关、资助方 | 论文、课题、专利、作品登记 | 学术或创作轨迹 |
| 社会参与 | 协会、基金会、活动主办方 | 理事名单、捐赠公示、活动照片 | 公开参与和共同出现 |
| 公开表达 | 媒体、本人账号、机构账号 | 采访、文章、视频、发言、社交内容 | 本人表达或公开露面 |
| 技术痕迹 | 域名注册商、应用商店、代码平台 | 域名历史、App 版本、代码提交 | 技术项目和时间轨迹 |
| 历史档案 | 图书馆、地方志、校史馆、报刊库 | 校友录、年鉴、旧报、讣告、方志 | 较早时期的履历和关系线索 |

**社媒(SOCMINT)只是"公开表达"这一行的一种来源**,不是每次人物调查都必须单独跑的独立层——
它只在"目标按常理可能公开表达/互动/露面"时才是重点来源之一。

## 轨迹叠加:单条记录 vs 轨迹判断

单条记录只证明单个事实,**多条独立记录叠加**才支撑轨迹判断。例:

- 学校录取榜单 → 只证明"被该校/项目录取",**不能单独推出"学习特别好"**。
- 若再叠加竞赛获奖 + 奖学金 + 保送 + 公示成绩 + 优秀毕业生 + 论文(彼此独立的记录),
  才能形成"长期学业表现较强"的**轨迹**判断。

写结论时把"这条记录证明什么、不证明什么"讲清楚,别用单条记录做过宽推断(见 templates.md
的"轨迹证据只证明什么"字段)。
