# 行为信号、动机与替代解释

用的是"公开"信息,不是只有"官方"信息:官方通报、当事人否认都只是**待评估的主张**,不因其
官方身份自动为真。但**反过来同样成立**——一方有自利动机,不代表它在说谎;删帖、沉默这类行为
看起来可疑,不代表它就是掩盖。这个模块教怎么从行为、动机、时机里**生成假设和搜索方向**,
而不是把"看起来可疑"直接当成不利结论。ACH 真正看重的是证据能否**区分**不同假设,不是它
是否可疑(见 methodology.md 与 CIA《Psychology of Intelligence Analysis》)。

前提摆在最前:本模块用于用户看清一件事。任何不利判断都要过证据门槛;标注"推断"或"仅供内部"
**不能替代**合理核实义务(《民法典》第一千零二十四至一千零二十六条:不得捏造歪曲事实,对可能
严重失实的内容负合理核实义务)。公众人物同样有名誉权。

## 1. 声明是待评估的主张——对称地怀疑

- 每条声明(官方通报、工作室声明、当事人否认、爆料)都是主张,先问:谁在说、有何利害、
  对这条主张有没有直接获取能力、在回应哪一条具体主张。
- **动机决定"下一步查什么",不直接决定真假**:
  - 声明方有自利动机(护盘、避责),**不证明声明为假**;
  - 爆料方有流量/报复/竞争/带货动机,**也不证明爆料为假**。
  - 两边动机都只是"这里要多查一层"的提示,不是天平砝码。
- **可信度看硬的,不看措辞风格**:直接获取能力、可验证的具体细节、独立印证,权重高于
  "否认得漂不漂亮"。一个给得出可验证细节、经得起追问的说法才加分——无论它来自哪一方。
- **沉默、拒答、删帖、法律声明本身不等于承认**,也不等于否认;它们是待解释的行为,不是自白。

## 2. 行为信号:先列替代解释,再谈指向

删帖、撤热搜、关评、限流、取关、不再同框、行程取消、反常沉默——这些是**多义行为**,
默认它们指向"欲盖弥彰"就是确认偏差。每个信号至少列**两个合理替代解释**,再看证据能不能在
它们之间做区分:

| 行为 | 可能指向"有事想藏" | 同样合理的其他解释 |
|------|-------------------|-------------------|
| 删帖/撤内容 | 消除不利证据 | 平台规则/自动审核、法务建议暂不回应、避免放大虚假传闻、保护第三方隐私 |
| 关评/限流 | 压制讨论 | 防网暴骚扰、平台默认设置、公关例行操作 |
| 取关/不同框 | 关系破裂坐实传闻 | 合同到期、普通关系变化、日程冲突 |
| 沉默 | 默认属实 | 法务要求禁言、不愿放大谣言、事情与其无关不值得回应 |
| 法律威胁 | 恐吓压事 | 确实被造谣、走正常维权流程 |

**只有当证据能排除掉替代解释时,某个行为才真正指向某个假设**;排除不掉,它就只是把该假设
列进矩阵、并提示一个搜索方向,不给不利假设加分。

**删帖不只是信号,更是线索**:被删内容常能找回——Wayback / archive.today、自由微信 / 自由微博
镜像(见 china-sources.md)。找回的原文往往比"它删了"这个动作本身有价值得多。

## 3. 共同原因检查:多个现象 ≠ 多份独立证据

删帖、关评、统一口径声明、减少公开露面,很可能全部来自**同一个公关决定**(或同一条平台规则、
同一次法务建议、同一个原始爆料)。四个现象源于一个决策,只算**一组信号**,不是四份独立证据。

汇聚软信号前,先问:**这些现象有没有可能是同一个共同原因触发的?** 是,就并成一组、按一份
证据的分量计;只有确属不同来源、不同触发的信号才可独立累加。忽略共同原因,是把相关性
误当成印证,会虚高置信度。

## 4. Cui bono:只提示动机,不证明事实

- 谁受益、谁在推、谁在压,回答的是"谁有动机",**不回答"事情是否发生"**。
- 有人在带节奏 与 事情本身为真,是两个独立问题,可同时成立或同时不成立。别用"有人获益"
  反推事实,也别用"有人带节奏"反推为假。

## 5. 置信度上限:软信号撑不起中/高的不利事实

- 单靠行为、措辞、时机、受益方分析,**最多形成低置信假设**。
- 要把一条**不利于某人的事实**判到中/高置信,必须有**可独立核验的直接证据**(一手文件、
  多个独立来源的直接指证、可验证的记录),而不是一堆多义行为的叠加。
- 正反都做:有没有一致指向"传闻为假/为夸大"的信号?两边摆出来再看天平,别只收一个方向。

## 6. 私人事项与绯闻:三重门槛,不因私密自动丢也不因猎奇扩展

私人事项不因其私密就自动丢弃,但纳入必须同时满足三条:

1. **真实性**:有**足以核实该主张的直接证据**——不机械要求某一种证据形式,但删帖/取关/沉默/
   含糊声明这类多义软信号本身不够。已被可靠证据确认的关系,就不该再当"绯闻",按事实处理。
2. **相关性**:与公共利益、履职能力、利益冲突、欺诈、胁迫、权力滥用,或用户的正当决策
   直接相关。
3. **比例性**:只呈现支撑该相关判断所必需的最少事实,不扩展到无关的私密细节。

处理矩阵:
- **已证实且相关** → 纳入结论,只写关系存在、时间范围和相关性;**不扩展感情细节、聊天内容、
  住址或家庭成员**。(正面例:某决策者与交易对手存在经可靠证据确认、未披露的私人关系,可能
  构成利益冲突——纳入,只陈述关系与冲突,不写私密细节。)
- **已证实但无关** → 不纳入报告。
- **未证实但可能高度相关** → 留作内部待核线索,继续找直接证据;不进入事实结论。
- **仅有软信号** → 可形成低置信假设,不得升为中/高置信的不利结论。
- **纯满足好奇、与决策或公共利益无关** → 不继续收集。

## 7. 结论分三层 + 分场景的证据门槛

产出时把内容明确分成三层,不混在一起:
- **已证事实**:有直接证据、经得起独立核验。
- **分析推断**:基于信号的判读,标注为推断、附置信度和依据。
- **内部待核线索**:尚未达标、但相关且有核实路径的线索(见"未证实线索的两层保留")。

同一结论,用途不同,门槛不同:
- **对外发布 / 重大权益决策(招聘/授信/投资)**:门槛最高,只能用已证事实;未证实的个人
  负面材料不得进入。
- **普通内部研究**:可呈现分析推断和待核线索,但必须标清层级,不得当成已证事实。

## 未证实线索的两层保留(取代"一律不丢弃")

"不丢弃"要分层,不是把所有拿不准的负面材料都倒给用户:
- **内部调查日志**:保留**有重大相关性、来源可追溯、仍有合理核实路径**的线索,继续找直接证据。
- **交付报告**:只放已证事实、明确标注的推断、以及少量确有必要说明的关键未知项。

无法说明相关性、没有核实路径、或只是重复传闻的个人负面内容,**从交付报告排除**;是否在调查
日志里保留一条最小索引,按保存期限和复核需要决定,不必为"信息完整"永久保留;尤其不能直接
塞进现实决策。这与"呈现相关的存疑信号供用户判断"不冲突——区别在于那条线索够不够格
(相关性 + 可核实路径)。
